# 🛒 Bol.com Advanced Scraper

Professional scraper for extracting product data from **Bol.com** (Netherlands & Belgium).

Designed for **dropshippers**, **market analysts**, and **repricing tools**.

## 🚀 Key Features

- **Anti-Bot Bypass:** Automatically handles Imperva protection and cookies.
- **Hidden Data:** Extracts **EAN (GTIN)** codes, **Seller Name** (Buy Box winner), and Stock status.
- **Multi-Region:** Supports both `bol.com/nl` (Netherlands) and `bol.com/be` (Belgium).
- **Recursive Crawling:** Can traverse categories, sub-categories, and storefronts automatically.

## ⬇️ Output Data

You will get a clean JSON/Excel/CSV dataset with:

- Product Title & URL
- **EAN / GTIN-13 Code** (Crucial for repricing!)
- Current Price & Currency
- Seller Name (Buy Block Winner)
- Main Image URL
- Review Rating

## 💡 How to use

1. **Start URLs:** Paste a link to any category (e.g., `https://www.bol.com/nl/nl/l/laptops/...`) or a specific product.
2. **Max Items:** Set the limit (e.g., 100).
3. **Proxy:** Residential Proxy (NL/BE) is recommended and enabled by default.
